# 📚 Relatório do Projeto - Catálogo de Livros

## 1. Objetivo
Criar uma aplicação web para organizar e visualizar livros de forma simples e intuitiva.

---

## 2. Tecnologias utilizadas
- React
- Vite
- CSS
- React Router DOM

---

## 3. Estrutura do sistema

O sistema contém:

- Home (página inicial)
- Catálogo
- Estante
- Perfil
- Login e Cadastro

---

## 4. Componentes

- Header (menu de navegação)
- Footer (informações finais)
- Home (estrutura principal)

---

## 5. Funcionalidades

- Navegação entre páginas sem recarregar
- Interface componentizada
- Estrutura organizada em páginas

---
## 6. Diagrama simplificado do sistema
Home → Catálogo → Detalhes → Estante
          ↓
       Login / Cadastro → Perfil
       
---
## 7. Fluxo da aplicação
Usuário acessa a Home
Navega para o Catálogo
Visualiza livros e adiciona à Estante
Pode ver detalhes de cada livro
Gerencia sua conta no Perfil

---
## 8. Conclusão
O projeto demonstra o uso de React para criação de interfaces modernas, utilizando componentes e rotas.

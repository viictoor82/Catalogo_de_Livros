# 📚 Catálogo de Livros

Projeto desenvolvido em React com Vite para organização de livros.

---

## 🚀 Funcionalidades

- Página inicial (Home)
- Catálogo de livros
- Estante do usuário
- Perfil
- Login e Cadastro
- Navegação com React Router
- Componentes reutilizáveis (Header e Footer)

---

## 🛠️ Tecnologias

- React
- Vite
- JavaScript
- CSS
- React Router DOM

---

## 📦 Como executar o projeto

### Clonar e rodar o projeto

```bash
git clone https://github.com/viictoor82/Catalogo_de_Livros.git
cd Catalogo_de_Livros
npm install
npm run dev
```
